# FitLog

FitLog is a modern, dark-themed workout planner and workout library built for people who want a simple way to discover workouts, organize their training plan, and track their workout progress.

## 🚀 Technologies Used

- **Next.js** – React framework for building the web application
- **React** – Component-based UI development
- **TypeScript** – Type-safe JavaScript development
- **Tailwind CSS** – Utility-first styling and responsive design
- **Lucide React** – Icons used throughout the interface
- **React Hot Toast** – Notifications and user feedback
- **Next/Image** – Optimized image rendering

## ✨ Key Features

### 1. Workout Library
Browse a collection of workouts covering different muscle groups, equipment types, durations, calories, and ratings.

### 2. Workout Sorting
Sort workouts by:
- Duration
- Calories burned
- Rating

This makes it easier to find workouts based on your preference.

### 3. My Plan
Add workouts to a personal workout plan and view the selected exercises in one place.

### 4. Saved Workouts
Save favorite workouts for quick access later. The navbar displays the current number of saved workouts.

### 5. Responsive Dark-Themed UI
FitLog provides a modern responsive interface that works across desktop, tablet, and mobile devices, with a dark gym-inspired design and highlighted accent colors.
